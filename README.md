# Hangman-Code
What is Hangman?
Hangman is a word game where you must guess the correct letter.
The word to guess is represented by a row of dashes representing each letter or number of the word.
This program is created by Java. The program can executed in Online Java Compiler.
The player has a total of six lives to guess the word correctly. The answers all relate to programming.
